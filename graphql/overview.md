# Overview

{% endhint %}

[GraphQL](https://graphql.org/) is a powerful query language that allows users to query the exact data they need and return it all with a single request. GraphQL queries access not only the properties of a single resource but simplifies the retrieval of its relationships to other entities. With GraphQL, users are now able to query records through an entire Rightsline hierarchy with a single request!

## Making a GraphQL request

All GraphQL requests should be made to the following endpoint using a **POST**:

`https://ris.rightsine.com/v4/graphql`
