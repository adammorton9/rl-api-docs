# Delete a Recipient Group

`DELETE` `https://ris.rightsline.com/v4/recipient-group/:id`

**Path Parameters**

| Name | Type    | Description                                     |
| ---- | ------- | ----------------------------------------------- |
| id\* | integer | The unique ID of the recipient group to delete. |

**Headers**

| Name           | Type   | Description             |
| -------------- | ------ | ----------------------- |
| x-api-key      | string | Your company's API key. |
| Authentication | string | Authentication token.   |

**Response**

```
true
```
