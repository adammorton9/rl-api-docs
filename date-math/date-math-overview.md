# Overview

Date Math™ is a complex and powerful tool. It allows you to calculate and create relationships between dates in the Rightsline system. Contact your Rightsline representative for a detailed walkthrough or further information.

### Endpoints

| Method | Endpoint                            | Description                                  |
| ------ | ----------------------------------- | -------------------------------------------- |
| POST   | /v4/date-math                       | [Create date math.](datemath-create.md)      |
| GET    | /v4/:entityType/:entityID/date-math | [Retrieve date math.](date-math-retrieve.md) |
| PUT    | /v4/date-math                       | [Update date math.](update-date-math.md)     |
| DELETE | /v4/date-math/:id                   | [Delete date math.](delete-date-math.md)     |
