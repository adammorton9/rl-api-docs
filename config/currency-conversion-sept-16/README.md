# Currency conversion

### Endpoints

| Method | Endpoint                     | Description                                                                |
| ------ | ---------------------------- | -------------------------------------------------------------------------- |
| POST   | /v3/currency/conversion      | [Create a currency conversion.](currency-conversion-create.md)             |
| GET    | /v3/currency/conversion/:id  | [Retrieve a currency conversion.](currency-conversion-retrieve.md)         |
| GET    | /v3/currency/conversion/list | [Retrieve all currency conversions.](currency-conversions-retrieve-all.md) |
| PUT    | /v3/currency/conversion/:id  | [Update a currency conversion.](currency-conversion-update.md)             |
| DELETE | /v3/currency/conversion/:id  | [Delete a currency conversion.](currency-conversion-delete.md)             |
